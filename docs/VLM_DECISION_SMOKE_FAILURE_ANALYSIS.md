# VLM Decision Smoke Failure Analysis

**Status: THE KAGGLE EXECUTION SUCCEEDED THROUGH A1; THE FROZEN A1 FEASIBILITY GATE THEN STOPPED THE RUN. THIS IS A SCIENTIFIC STOP, NOT A MODEL-LOAD FAILURE.**

**Scope:** the bounded 48-request development smoke only. This document separates three things that must not be conflated: (1) the preserved local laptop load failure, (2) Kaggle infrastructure failures that occurred before any model request, and (3) the A1 behavioral result that correctly triggered the frozen hard gate.

## 2. Preserved local failure (historical)

The local laptop run at `results/vlm_decision_smoke/real/` stopped during the transfer of the frozen checkpoint to the GPU, before any request:

```text
AcceleratorError: CUDA error: CUDA-capable device(s) is/are busy or unavailable
```

The failure occurred at `self._model.to(self.device)` after 50.3615 s of load wall time. The checkpoint had already verified. The host was an 8 GB RTX 4060 Laptop GPU; free memory after the failure was 7,441,743,872 bytes, already below the 7,520,892,432-byte weight set before runtime and generation allocations. An earlier load-only probe had allocated 7,628,753,408 bytes and reserved 7,874,805,760 bytes, leaving zero free bytes.

This record is preserved unchanged at `results/vlm_decision_smoke/real/`. It is not overwritten by the Kaggle artifacts. The local failure does not establish that the model is fundamentally too large; it establishes that this host did not provide a working allocation path under the frozen bf16/no-offload/no-quantization constraints.

## 3. Kaggle infrastructure failures before inference

### Version 1 - staged bytecode in the source manifest

Exact error:

```text
RuntimeError: missing staged source file: scripts/__pycache__/aggregate_results.cpython-313.pyc
```

Cause: `SOURCE_MANIFEST.json` included generated `__pycache__/*.pyc` files that Kaggle does not preserve in uploaded datasets. The source dataset was regenerated to 158 files with bytecode excluded, and the kernel verifier was updated to skip generated bytecode. No scientific artifact changed.

### Version 2 - Windows path separators in the freeze keys

The freeze verifier could not resolve the frozen source entry for `src/ruleshift/evaluator/vlm_decision.py` on the Linux staging copy.

Cause: `freeze.json` stores source keys with Windows backslashes, while Linux produces `/` from `Path.relative_to(...)`. The source file itself was byte-identical to the frozen hash `sha256:63c537a17755e20d0dffe20cb68295ce8acd8e12f6bb562a3077bfc3d6c34a14`; this was a lookup-key defect, not a file mutation. A path-normalizing shim was added and a local CPU preflight passed.

### Version 3 - request-manifest mismatch at preflight

Exact error:

```text
ValueError: frozen manifest differs from rebuilt manifest
```

Stage: preflight. Model calls: 0. The image pixels and all non-image fields were still being compared against a manifest rebuilt by Pillow 13.0.0 on Kaggle; the frozen manifest had been built with the local Pillow encoder. PNG bytes are encoder-dependent even when decoded pixels are identical. The exact differing field was not printed, so the PNG attribution is supported by the fix rather than by a logged field-level diff.

Version 4 removed the platform dependence: the shim loads the frozen PNG pixels for every image request, keeps the pixel digest strict, and uses the frozen PNG byte hash when rebuilding the manifest record. Preflight then passed exactly. This changes only path/hash portability; it does not change prompts, menus, labels, images, parser, scorer, or gates.

### Version 4 - execution reached the scientific gate

Version 4 passed hardware checks, source verification, checkpoint verification, preflight, and the 48-request stub dry run. The real run loaded the model and issued all 12 A1 requests. It then stopped on the A1 gate.

## 4. The A1 gate failure

A1 was not an infrastructure failure:

- 12/12 requests completed.
- 12/12 responses were valid JSON and parsed without fallback.
- There were zero request failures and zero retries.
- GPU generation time was 24.1888 s; mean latency was 2,020.8 ms.

The behavior was nevertheless degenerate:

- Actions: 12 COMMIT, 0 PROBE_SIGN, 0 PROBE_BLUE.
- Optimal actions on the same 12 contexts: 4 COMMIT, 4 PROBE_SIGN, 4 PROBE_BLUE.
- Optimal-action accuracy: 0.3333 (4/12).
- Mean regret: 2.0928; maximum regret: 5.025.
- Under-probe rate: 0.6667 (8/12); over-probe rate: 0.0.
- Distinct valid actions: one (`COMMIT`).
- Gate: `valid_at_least_11 = true`, `non_constant = false`, overall fail.

These are exactly the always-commit baseline numbers on the same contexts. The model did not merely under-probe slightly; it reproduced a constant policy.

### Why the gate stopped the run

The gate is part of the frozen protocol. Its purpose is to prevent A2/A3/control spending when the text-only A1 arm is already constant, because a constant A1 arm cannot support the intended comparison of prior/evidence text, posterior text, and posterior image. Running A2 or A3 after this result would change the pre-registered stopping rule and would spend requests on an uninformative comparison.

### Plausible contributor, not a proven cause

The frozen A1 instruction ends with the literal example:

```text
Return ONLY one compact JSON object with exactly this key: {"selected_action":"COMMIT"} (replace COMMIT with one feasible action).
```

All 12 outputs were exactly `{"selected_action":"COMMIT"}`, each 8 output tokens. A small model copying the example is a plausible schema/example-anchoring contributor. However, this run has one prompt format, one decoding configuration, and 12 contexts; it cannot separate example anchoring from a genuine COMMIT preference, prompt confusion, or a capability limitation. No causal claim is made.

Changing the example, reordering actions, adding a format control, or otherwise tuning the prompt is a scientific protocol change. It was not authorized and was not performed. It would require a new freeze and a new human decision, not a retry of this smoke.

## 5. What is not the cause

- Not checkpoint integrity: the aggregate hash and exact revision verified.
- Not local-file availability: the snapshot was mounted and read locally.
- Not checkpoint loading on Kaggle: the model loaded in bf16.
- Not prompt rendering or parser behavior: 48 prompts rebuilt exactly in preflight and all 12 responses parsed.
- Not the 48-request cap: only 12 were attempted; the stop came from the A1 gate.
- Not a request failure: 12/12 completed with status `ok`.
- Not a cache or accounting bug: 12 responses and 12 cache entries are present.
- Not a data leak: preflight found zero forbidden-label terms.
- Not a missing image path in A3: no A3 request was issued after the A1 stop.

## 6. Why the run stopped rather than continuing

The protocol is explicit: stop at a hard arm gate. Continuing would have violated the frozen analysis plan and the 48-request discipline. The stop leaves A2, A3, nuisance, and diagnostic unevaluated, but it preserves the validity of the A1 result and avoids presenting a post-gate exploratory comparison as if it were pre-registered evidence.

## 7. Impact

The smoke produced:

- A valid infrastructure result: the frozen stack loads and issues valid direct-action outputs on Kaggle T4.
- A valid but degenerate A1 behavioral result: 12/12 valid, all COMMIT, equal to the always-commit baseline, gate failure.

It did not produce:

- Any A2 or A3 result.
- Any model consumption of the RGB posterior card.
- Any nuisance or diagnostic result.
- Any evidence about OCR, chart reading, visual posterior use, or multimodal decision quality.
- Any basis for promoting the smoke to a pilot.

## 8. Remediation options, none performed

These are options for a new human decision, not actions already taken:

1. **Stop the VLM decision line at this smoke (recommended).** Preserve the result as a negative feasibility signal and do not spend more compute under the current prompt.
2. **Authorize a new, separately pre-registered smoke with a revised A1 response format.** This is a scientific change: new prompt, new freeze, new manifest, new preflight, and a new request budget. It must not be described as a retry.
3. **Authorize a broader diagnostic study of prompt format and action anchoring.** This is also a new experiment, not the current smoke; it must not be merged into the 48-request result.
4. **Authorize a larger pilot.** Not supported by this result and not authorized.
