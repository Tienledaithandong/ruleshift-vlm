# reports/

Generated analysis reports are written here by the scripts in `scripts/`.
They are git-ignored (`reproduce_all.py` regenerates them) and until a real
frozen VLM is used they are explicitly labelled SYNTHETIC by the generating
code. The only committed file besides this README is `w6_validation.md`, which
is a status/PENDING document rather than a generated result.

`w6_validation.md` is a status/PENDING document, not a result.

See `docs/RUNBOOK.md` for which command writes which report and for the
conditions under which any report may be treated as empirical.
