# Week 10 — Error decomposition by surgical intervention (SYNTHETIC)

**No VLM was run.** Every row uses a deterministic stub. This shows that single-component attribution is *measurable*, not where a real model's errors come from. **No generality claim** is made.

The baseline uses model-estimated rule probabilities. The belief intervention substitutes the exact prior for the public card lottery. The oracle-outcome intervention replaces VLM outcome predictions with noise-free public rule semantics. The public-text row is a **control**: the stub backend has no image path, so the intervention changes nothing by construction. It is listed to show the row exists, not as a measured zero effect.

| Intervention | Mean regret | Error rate | Regret reduction vs baseline | Label coverage |
|---|---:|---:|---:|---:|
| baseline | 6.250 | 0.500 | +0.000 | 1.000 |
| oracle_belief | 6.250 | 0.500 | +0.000 | 1.000 |
| oracle_outcomes | 6.250 | 0.500 | +0.000 | 1.000 |
| public_text | 6.250 | 0.500 | +0.000 | 1.000 |
| oracle_both | 6.250 | 0.500 | +0.000 | 1.000 |

Largest measured reduction in this synthetic run: **none (no intervention reduced mean regret)**. When all rows are identical the harness is only proving it can run, not localising any error. With a real VLM this would be the candidate bottleneck; here it is an artifact of stub design and must not be reported as a finding about vision-language agents.
